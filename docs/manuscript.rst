The manuscript proves the Gaussian--Haar equivalence for knot type, full
stick-number support, exact pair-distance and expected planar-crossing laws,
and the finite Calvo classifier used for the :math:`N=6` audit.  It also states
precisely which topology, probability, and classification theorems remain
external to the Lean development.

The committed PDF is built from the committed TeX source.  The fixed displayed
date prevents an ordinary rebuild from silently changing the paper's stated
version date.
